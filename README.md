# Veilfall: Triune

Inventory for Triune. Drop these in your MQ `lua` folder:

- `vfti.lua`
- `vft/inv/`
- `vft/brand.lua`
- `vft/chat.lua`
- `vft/vf-mark.png`
- `vft/vf-bag.png`
- `bags.lua` (optional)

Fire up the loader:

```
/lua run vfti
```

That mini bar is the front door. Bag icon opens the full window.

Make a hotkey named **VFInv** with:

```
/vf inv
```

Same as `/vf bags`. Needs the loader running.

Locks land in `vft/config/` on your machine.
